# 제품 요구사항 문서 (PRD)
## 개인 개발 블로그 - Notion CMS 활용

**문서 버전**: 1.0  
**최종 수정일**: 2026-08-08  
**작성자**: 개발팀

---

## 1. 개요

### 1.1 프로젝트 소개
**프로젝트명**: 개인 개발 블로그  
**목표**: Notion을 CMS로 활용하여 기술 블로그 운영  
**주요 가치**: 글 작성 단순화, 자동 배포, 일관된 사용자 경험 제공

### 1.2 CMS 선택 이유
- **컨텐츠 관리 용이성**: Notion의 직관적인 UI로 편리한 글 작성
- **자동 동기화**: Notion 데이터베이스 업데이트 시 자동으로 블로그에 반영
- **비용 효율성**: 별도의 백엔드 인프라 구축 불필요
- **확장성**: Notion API를 통한 다양한 기능 추가 가능

### 1.3 대상 사용자
- **주 사용자**: 개발자 (개인)
- **보조 사용자**: 기술 관심층
- **예상 월간 방문자**: 100~500명 (MVP 단계)

## 2. 주요 기능 (Features)

### 2.1 핵심 기능

#### 2.1.1 블로그 글 목록 조회
- **설명**: Notion 데이터베이스에서 발행된 글의 목록을 가져와 홈페이지에 표시
- **주요 사항**:
  - 최신순 정렬
  - 페이지네이션 지원 (한 페이지당 10개 항목)
  - 제목, 요약, 작성일, 카테고리 표시
  - 발행 상태가 "발행됨"인 글만 노출

#### 2.1.2 개별 글 상세 페이지
- **설명**: 클릭한 글의 전체 내용을 표시
- **주요 사항**:
  - Notion의 Rich Text 포맷 지원 (제목, 본문, 코드블록, 이미지 등)
  - 메타데이터 표시 (작성일, 수정일, 카테고리, 태그)
  - 목차 자동 생성 (h2, h3 기준)
  - 이전/다음 글 네비게이션

#### 2.1.3 카테고리별 필터링
- **설명**: 카테고리를 선택하여 해당 글들만 보기
- **주요 사항**:
  - 전체 카테고리 목록 표시
  - 각 카테고리별 글 개수 표시
  - URL 기반 라우팅 (예: `/category/react`)
  - 필터 UI 반응형 처리

#### 2.1.4 검색 기능
- **설명**: 제목, 본문, 태그 기반 전문 검색
- **주요 사항**:
  - 클라이언트 측 검색 지원 (초기 로드 후 빠른 검색)
  - 검색어 입력 중 실시간 결과 표시
  - 검색 결과 강조 표시
  - "검색 결과 없음" 안내 메시지

#### 2.1.5 반응형 디자인
- **설명**: 다양한 디바이스에서 최적의 사용자 경험 제공
- **주요 사항**:
  - Desktop: 1024px 이상
  - Tablet: 640px ~ 1023px
  - Mobile: 640px 이하
  - 터치 기반 인터랙션 지원

## 4. Notion 데이터베이스 구조

### 4.1 데이터베이스 스키마

| 필드명 | 필드 타입 | 설명 | 필수 여부 | 예시 |
|--------|---------|------|---------|------|
| Title | Title | 글의 제목 | ✓ | "Next.js 성능 최적화 가이드" |
| Category | Select | 글의 카테고리 | ✓ | React, Node.js, TypeScript |
| Tags | Multi-select | 글의 태그 (다중선택) | ✗ | "성능", "최적화", "튜토리얼" |
| Published | Date | 글 발행일 | ✓ | 2026-08-08 |
| Status | Select | 글의 상태 | ✓ | "발행됨" / "초안" |
| Content | Page content | 글의 본문 내용 | ✓ | Notion 페이지 본문 |

### 4.2 데이터베이스 설정
- **필터**: `Status` = "발행됨" (블로그 노출용)
- **정렬**: `Published` 최신순 (내림차순)
- **페이지 크기**: 최대 100개 항목 (API 호출 최적화)

## 5. 화면 구성 (UI Structure)

### 5.1 홈 페이지 (`/`)

**목적**: 최근 발행된 글 목록 표시

**구성 요소**:
- **헤더**: 사이트 제목, 네비게이션 메뉴
- **히어로 섹션**: 사이트 소개 (선택사항)
- **검색 바**: 글 검색
- **카테고리 필터**: 사이드바 또는 드롭다운
- **글 카드 목록**: 
  - 제목, 요약, 작성일, 카테고리 표시
  - 호버 효과 (데스크톱)
  - 페이지네이션 또는 무한 스크롤
- **푸터**: 저작권, 링크

**응답 속도**: 초기 로드 < 2초

### 5.2 글 상세 페이지 (`/blog/[slug]`)

**목적**: 선택한 글의 전체 내용 표시

**구성 요소**:
- **헤더**: 글 제목, 메타데이터 (작성일, 카테고리, 태그)
- **목차**: 글 내용의 주요 제목 자동 생성
- **본문 영역**: Notion에서 가져온 Rich Text 렌더링
  - 텍스트 포맷 (굵게, 기울임, 코드)
  - 제목 계층 (h1 ~ h6)
  - 리스트 (순서 있음/없음)
  - 코드블록 (문법 하이라이팅 포함)
  - 인용문
  - 이미지 (반응형)
- **사이드바** (데스크톱):
  - 목차 (Sticky)
  - 공유 버튼
  - 저자 정보
- **네비게이션**:
  - 이전 글 / 다음 글 버튼
  - 블로그 목록으로 돌아가기
- **푸터**: 관련 글 추천

**응답 속도**: 상세 페이지 로드 < 1초

### 5.3 카테고리 페이지 (`/category/[category]`)

**목적**: 특정 카테고리의 글 목록 표시

**구성 요소**:
- **헤더**: 카테고리 제목
- **글 개수**: "총 X개의 글"
- **글 목록**: 홈 페이지와 동일한 카드 레이아웃
- **정렬 옵션**: 최신순, 오래된순 (선택사항)
- **네비게이션**: 다른 카테고리로 이동

### 5.4 검색 결과 페이지 (`/search?q=keyword`)

**목적**: 검색어에 해당하는 글 표시

**구성 요소**:
- **검색 바**: 현재 검색어 표시, 수정 가능
- **필터 옵션**: 카테고리별 필터 (선택사항)
- **결과 표시**:
  - 총 검색 결과 개수
  - 검색어 강조 표시
  - 일치도 정렬
- **"검색 결과 없음"**: 안내 메시지 및 인기 글 추천

## 8. 기술 고려사항

### 8.1 API 제한사항
- **API 속도 제한**: Notion API는 초당 3회 요청 제한
  - **해결책**: 캐싱 전략 (ISR - Incremental Static Regeneration)
- **페이지 크기**: 한 번에 최대 100 블록 조회
  - **해결책**: 재귀적 블록 조회

### 8.2 성능 최적화
- **정적 생성 (SSG)**: 빌드 타임에 모든 글 페이지 사전 생성
- **증분 정적 재생성 (ISR)**: 새 글 발행 시 자동 갱신
- **이미지 최적화**: Next.js Image 컴포넌트 활용
- **캐싱**: Notion API 응답 캐싱 (15분 ~ 1시간)

### 8.3 에러 처리
- **API 오류**: Notion 연결 실패 시 사용자 친화적 메시지 표시
- **잘못된 요청**: 존재하지 않는 글/카테고리에 대한 404 페이지
- **타임아웃**: 요청 시간 초과 처리

### 8.4 보안
- **API Key 보호**: `.env.local`에서만 로드
- **CORS**: Vercel 환경에서 자동 처리
- **XSS 방지**: Notion의 Rich Text 렌더링 시 새니타이징
